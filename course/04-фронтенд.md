# Лекция 4. Фронтенд: JavaScript по модулям

## 4.1. Необходимый минимум языка

### Объявления

```javascript
const x = 5;    // нельзя переприсвоить
let y = 10;     // можно
```

`var` не используем — у него другая, устаревшая область видимости.

### Функции и стрелки

```javascript
function money(value) { return value * 2; }     // обычная
const money = value => value * 2;               // стрелочная, короткая запись
const sum = (a, b) => a + b;
```

Стрелочные функции важны ещё и тем, что не создают собственный `this` —
поэтому их безопасно передавать в обработчики событий.

### Шаблонные строки

```javascript
const name = 'Магнит';
const html = `<div class="tab">${name}</div>`;   // обратные кавычки
```

`${...}` подставляет значение. Можно переносить строки. Вся наша генерация
разметки построена на этом.

### Массивы

```javascript
const items = [1, 2, 3];
items.map(x => x * 2)                 // [2, 4, 6]  — преобразовать каждый
items.filter(x => x > 1)              // [2, 3]     — отобрать
items.reduce((sum, x) => sum + x, 0)  // 6          — свернуть в одно значение
items.find(x => x === 2)              // 2          — первый подходящий
items.sort((a, b) => b - a)           // [3, 2, 1]  — отсортировать
[...items]                            // копия (spread)
```

`reduce` встречается в проекте часто — например, суммы лимитов.

### Объекты и деструктуризация

```javascript
const company = { id: 2, name: 'Магнит' };
const { name } = company;                    // достать поле в переменную
const copy = { ...company, name: 'Новое' };  // копия с заменой поля
```

### Асинхронность

Запрос к серверу занимает время. JavaScript не ждёт — он идёт дальше, а
результат обещает вернуть позже. Это обещание и есть **Promise**.

```javascript
async function load() {
  const response = await fetch('/api/companies?q=маг');   // ждём ответа
  const data = await response.json();                     // ждём разбора
  return data;
}
```

`async` помечает функцию как асинхронную, `await` внутри неё останавливает
выполнение **этой функции** до готовности результата, не блокируя страницу.

Несколько запросов сразу:

```javascript
const [a, b, c] = await Promise.all([fetchA(), fetchB(), fetchC()]);
```

Все три уходят одновременно, ждём самый долгий. Последовательные `await`
заняли бы сумму времён.

### Модульный шаблон (IIFE)

Каждый наш файл выглядит так:

```javascript
const Format = (() => {
  const nf = ...;                    // приватное: снаружи не видно
  const money = v => ...;            // тоже приватное
  return { money, compact };         // публичное: только это доступно
})();
```

`(() => { ... })()` — функция, объявленная и тут же вызванная. Всё внутри
скрыто, наружу отдаётся только то, что в `return`. Это «модуль» без сборщика.
Снаружи работает `Format.money(100)`, а `Format.nf` недоступно.

## 4.2. `format.js` — форматирование (40 строк)

Самый простой модуль: **чистые функции**. На одинаковый вход всегда одинаковый
выход, ничего не меняют вовне. Такие функции проще всего тестировать.

```javascript
const nf = (min, max) => new Intl.NumberFormat('ru-RU', {
  minimumFractionDigits: min, maximumFractionDigits: max,
});
```

> **Где это в коде:** `web/js/format.js:3` — фабрика `nf`; `web/js/format.js:14` —
> `compact`; `web/js/format.js:34` — `escape`; `web/js/format.js:37` — `normalize`.

`Intl.NumberFormat` — встроенный в браузер форматтер чисел. `'ru-RU'` даёт
пробел как разделитель тысяч и запятую как десятичный: `1 234 567,89`.
Писать это вручную не нужно.

```javascript
const compact = v => {
  const abs = Math.abs(v);
  if (abs >= 1e9) return nf(2, 2).format(v / 1e9) + ' млрд ₽';
  if (abs >= 1e6) return nf(1, 1).format(v / 1e6) + ' млн ₽';
  ...
};
```

`1e9` — научная запись, миллиард. На карточках нужен короткий вид
(«1,88 млрд ₽»), в таблицах — полный.

```javascript
const escape = s => String(s).replace(/[&<>"]/g, m =>
  ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[m]));
```

**Это защита от XSS.** Мы строим HTML из строк. Если имя компании будет
`<script>alert(1)</script>`, браузер выполнит это как код. `escape` превращает
`<` в `&lt;`, и текст остаётся текстом. Правило: **любое значение, попадающее
в HTML-строку, проходит через `escape`.**

### Демонстрация: что возвращают функции форматирования

```bash
node -e "$(cat web/js/format.js); console.log(Format.compact(1880000000))"
```

Все функции разом:

```
money(21048740)      -> 21 048 740
rub(21048740)        -> 21 048 740 ₽
compact(1880000000)  -> 1,88 млрд ₽
compact(494300000)   -> 494,3 млн ₽
pct(43.21)           -> 43,2%
delta(100, 125)      -> +25,0%
delta(100, 80)       -> −20,0%
escape("<script>")   -> &lt;script&gt;alert(1)&lt;/script&gt;
normalize("ООО Ёлка")-> ооо елка
```

**Разбор по строкам:**

- `money` и `rub` ставят **неразрывные пробелы** между разрядами — это делает
  `Intl.NumberFormat('ru-RU')`, а не наш код.
- `compact` выбирает единицу по величине: миллиарды с двумя знаками, миллионы
  с одним. На карточке «1,88 млрд ₽» читается мгновенно, а «1 880 000 000 ₽»
  требует пересчёта в уме.
- `delta` возвращает знак **−** (U+2212, минус), а не дефис: типографски это
  разные символы, и минус выравнивается по ширине с плюсом.
- `escape` превратил `<script>` в безобидный текст. Именно это спасает от XSS,
  когда имя компании подставляется в HTML-строку.
- `normalize` убрал регистр и заменил «ё» на «е» — поиск «елка» найдёт «Ёлку».

## 4.3. `api.js` — единственное место, знающее про сервер

```javascript
const API = (() => {
  const BASE = '/api';
  let offline = false;

  async function call(path) {
    const res = await fetch(BASE + path, { headers: { Accept: 'application/json' } });
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json();
  }
```

> **Где это в коде:** `web/js/api.js:15` — низкоуровневый `call`;
> `web/js/api.js:23` — `withFallback`; `web/js/api.js:42` — `encodeURIComponent`
> при сборке адреса поиска.

`fetch` — встроенная функция запроса. Важная тонкость: **`fetch` не считает
ошибкой код 404 или 500** — обещание выполняется успешно, просто `res.ok`
будет `false`. Проверять статус нужно самому, что мы и делаем.

```javascript
  async function withFallback(path, mockFn) {
    if (offline) return mockFn();
    try {
      return await call(path);
    } catch (e) {
      if (typeof DemoData === 'undefined') throw e;
      offline = true;
      console.info('[АББ] Бэкенд не отвечает — включены демо-данные');
      return mockFn();
    }
  }

  return {
    searchCompanies: q => withFallback(`/companies?q=${encodeURIComponent(q)}&limit=8`,
                                       () => DemoData.search(q)),
    ...
  };
})();
```

Две вещи:

**`encodeURIComponent`** превращает «маг» в `%D0%BC%D0%B0%D0%B3`. В URL
допустимы только ASCII-символы. Мы наткнулись на это в консоли: `curl` с
кириллицей в адресе получал `400 Invalid HTTP request`, потому что curl,
в отличие от браузера, сырые байты не кодирует.

**Fallback на демо-данные** позволяет открыть интерфейс без бэкенда. В
продакшене этот механизм надо удалить: показывать выдуманные цифры вместо
ошибки — опасно. Мы поэтому же добавили жёлтый значок «демо-данные».

## 4.4. `search-bar.js` — строка поиска (166 строк)

Здесь три классические задачи интерфейса.

### Задача 1. Debounce

Без него запрос уходил бы на каждую букву: «м», «ма», «маг»… — 14 запросов
на слово «Магнитогорский».

```javascript
let debounceTimer = null;

input.addEventListener('input', () => {
  const text = input.value.trim();
  clearTimeout(debounceTimer);                       // отменяем прошлый таймер
  if (text.length < 3) { closeDropdown(); return; }
  debounceTimer = setTimeout(() => loadSuggestions(text), 160);
});
```

> **Где это в коде:** `web/js/search-bar.js:19` — `debounceTimer`;
> `web/js/search-bar.js:18` — счётчик `requestCounter`;
> `web/js/search-bar.js:108` — обработка клавиш; `web/js/search-bar.js:70` —
> выбор мышью через `mousedown`; `web/js/search-bar.js:79` — подсветка совпадения.

Каждое нажатие отменяет предыдущий таймер и ставит новый. Запрос уходит,
только если человек замолчал на 160 мс. Плюс порог в 3 символа отсекает
бессмысленно широкие запросы.

### Задача 2. Гонка ответов

Ответы могут вернуться не в том порядке, в каком ушли запросы. Ответ на «маг»
способен прийти после ответа на «магнит» и перезаписать его.

```javascript
let requestCounter = 0;

async function loadSuggestions(text) {
  const requestId = ++requestCounter;
  let result = [];
  try { result = await API.searchCompanies(text); } catch { result = []; }
  if (requestId !== requestCounter) return;     // ответ устарел — выбрасываем
  suggestions = result;
  renderDropdown(text);
}
```

Простой счётчик: применяем только ответ на самый свежий запрос. Приём
работает в любом интерфейсе с автодополнением.

### Демонстрация: гонка ответов и счётчик запросов

Смоделируем ситуацию: пользователь набрал «маг», затем дописал до «магнит».
Первый запрос отвечает дольше (300 мс против 50 мс) — так бывает, когда
короткий префикс подходит большему числу строк.

```javascript
async function naive(text) {            // без защиты
  const r = await search(text);
  applied.push(`применён ответ на «${r.text}»`);
}

async function guarded(text) {          // со счётчиком
  const my = ++counter;
  const r = await search(text);
  if (my !== counter) { console.log('ОТБРОШЕН'); return; }
  applied.push(`применён ответ на «${r.text}»`);
}
```

```
=== без защиты ===
  применён ответ на «магнит»
  применён ответ на «маг»
  итог на экране: «маг»  ← не то, что в поле ввода

=== со счётчиком запросов ===
  применён ответ на «магнит»
  ОТБРОШЕН устаревший ответ на «маг»
```

**Что произошло.** Оба запроса ушли почти одновременно. Ответ на «магнит»
пришёл первым и отрисовался — правильно. Затем пришёл ответ на «маг» и
перезаписал список: пользователь видит подсказки для «маг», хотя в поле
написано «магнит».

**Как лечит счётчик.** Каждому запросу присваивается номер (`++counter`).
Перед применением ответа номер сверяется с текущим значением счётчика: если
за это время ушёл ещё один запрос, счётчик уже больше, и ответ выбрасывается.

Приём универсален: он нужен везде, где ответы могут прийти не в том порядке,
в каком уходили запросы — автодополнение, фильтры, поиск по мере ввода.
В проекте: `web/js/search-bar.js:18` и `web/js/search-bar.js:37`.

### Задача 3. Клавиатура

```javascript
input.addEventListener('keydown', event => {
  const isOpen = dropdown.classList.contains('is-open');
  if (event.key === 'ArrowDown' && isOpen) {
    event.preventDefault();
    highlight((highlightedIndex + 1) % suggestions.length);
  } else if (event.key === 'Enter') {
    event.preventDefault();
    if (isOpen && highlightedIndex > -1) selectCompany(suggestions[highlightedIndex]);
  } else if (event.key === 'Escape') closeDropdown();
});
```

`% suggestions.length` — остаток от деления, зацикливает список: после
последнего элемента снова первый. `preventDefault()` отменяет стандартное
поведение (Enter отправил бы форму, стрелка увела бы курсор).

Ещё деталь — выбор мышью:

```javascript
node.addEventListener('mousedown', event => {
  event.preventDefault();
  selectCompany(...);
});
```

Именно `mousedown`, а не `click`. Клик срабатывает после `blur` поля ввода,
список к тому моменту уже закрылся бы. `preventDefault` не даёт полю потерять
фокус.

### Подсветка совпадения

```javascript
function highlightMatch(value, text) {
  const position = Format.normalize(value).indexOf(Format.normalize(text));
  if (position < 0) return Format.escape(value);
  return Format.escape(value.slice(0, position)) +
         '<b>' + Format.escape(value.slice(position, position + text.length)) + '</b>' +
         Format.escape(value.slice(position + text.length));
}
```

`normalize` приводит к нижнему регистру и заменяет «ё» на «е», чтобы поиск
не зависел от регистра и буквы ё. Каждый кусок экранируется отдельно, а теги
`<b>` добавляются уже после — иначе экранирование съело бы и их.

## 4.5. `tab-tree.js` — дерево вкладок (546 строк)

Самый большой модуль. Отвечает за три уровня вкладок, их состояние и геометрию.

### Состояние

```javascript

  view: null,           // 'company' | 'events' — что выбрано на 1-м уровне
  section: null,        // 'main' | 'statements' | 'limits' | ...
  group: 'balance',     // какой раздел отчётности
  eventFilter: 'critical',
  attribute: null,      // раскрыта ли структура ГК
  groupSelection: null, // выбранная в ГК компания для перехода

```

> **Где это в коде:** `web/js/tab-tree.js:26` — объект `state`;
> `web/js/tab-tree.js:58` — `createTab`; `web/js/tab-tree.js:207` — `syncTabs`;
> `web/js/tab-tree.js:443` — `renderContent`.

Один объект описывает интерфейс целиком. Любое действие меняет состояние и
вызывает перерисовку. Это упрощённая версия того, что делают React и Vue.

### Создание вкладки

```javascript
function createTab({ label, labelFlag, value, note, isStatic, index = 0, onClick }) {
  const node = document.createElement(isStatic ? 'div' : 'button');
  node.className = 'tab' + (isStatic ? ' is-static' : '');
  node.style.animationDelay = index * 45 + 'ms';
  if (!isStatic) {
    node.type = 'button';
    node.addEventListener('click', onClick);
  }
  node.innerHTML = ...;
  return node;

```

Аргумент — объект (именованные параметры): при вызове видно, что означает
каждое значение. `index * 45 + 'ms'` даёт лесенку появления карточек.

Кликабельное — `<button>`, справочное — `<div>`. Это не косметика: кнопка
доступна с клавиатуры и озвучивается как кнопка.

### Построить один раз, дальше менять классы

```javascript
function syncTabs() {
  tabNodes.company.classList.toggle('is-active', companyOpen);
  ...
  setLevelVisible(sectionLevel, companyOpen || eventsOpen);
  requestAnimationFrame(() => { fitTopRow(); layoutBranch(); });
}
```

Вкладки создаются один раз на загрузку компании, при кликах меняются только
классы. Если пересоздавать узлы, анимация появления проигрывалась бы заново
при каждом клике — мы это уже проходили.

`classList.toggle(name, condition)` добавляет класс, если условие истинно, и
убирает иначе.

`requestAnimationFrame` откладывает код до ближайшей перерисовки — к этому
моменту браузер уже применил классы и посчитал размеры. Измерять раньше
бессмысленно.

### inert — скрытое не должно быть доступно с клавиатуры

```javascript
function setLevelVisible(level, visible) {
  level.classList.toggle('is-open', visible);
  level.toggleAttribute('inert', !visible);
}
```

Схлопнутый уровень визуально не виден, но его кнопки остаются в обходе по
Tab. Атрибут `inert` полностью исключает поддерево из взаимодействия.

### Измерение геометрии

```javascript
function offsetWithin(node, ancestor) {
  let x = 0;
  while (node && node !== ancestor) {
    x += node.offsetLeft;
    node = node.offsetParent;
  }
  return x;
}
```

`offsetLeft` — смещение относительно ближайшего позиционированного предка.
Поднимаемся по цепочке и суммируем, получая координату относительно корня
дерева.

> **Где это в коде:** `web/js/tab-tree.js:281` — `offsetWithin`;
> `web/js/tab-tree.js:385` — `layoutBranch`; `web/js/tab-tree.js:437` —
> `setLevelVisible` с атрибутом `inert`.

Ключевое свойство: **`offsetLeft` не учитывает `transform`.** Мы двигаем
строки трансформацией, и измерения остаются «чистыми» — они описывают
раскладку до анимации. Если бы использовали `getBoundingClientRect()`,
измерения зависели бы от текущего кадра анимации.

### Выравнивание строк

```javascript
function layoutBranch() {
  const toRight = treeRoot.classList.contains('branch-right');
  const gutter = cssPx('--marker-gutter');
  const target = toRight ? treeRoot.offsetWidth - gutter : gutter;

  rows.forEach(row => {
    const edge = nearEdge(row, toRight);
    const shift = Math.round(target - edge);
    row.style.transform = shift ? `translateX(${shift}px)` : '';
  });
}
```

Цель фиксирована — граница поля. Каждая строка сдвигается так, чтобы её
ближний край совпал с целью. Раньше цель зависела от нажатой карточки, и
раскладка «прыгала» при выборе разных вкладок.

`cssPx` читает переменную CSS:

```javascript
const cssPx = name => parseInt(getComputedStyle(treeRoot).getPropertyValue(name), 10) || 0;
```

Значение задано в CSS и меняется медиазапросами — JS просто берёт актуальное.

### Двухступенчатый подбор ширины верхней строки

Задача: ИНН нельзя разрывать, длинное название нельзя рвать посреди слова.

> **Где это в коде:** `web/js/tab-tree.js:317` — `measureRow`;
> `web/js/tab-tree.js:325` — `fitTopRow`; `web/css/styles.css:308` — классы

Приём называется «измерить и вернуть»: добавляем класс, читаем размер,

## 4.7. `events.js` — поиск отклонений (216 строк)

## 4.8. `xlsx-writer.js` — Excel без библиотек (197 строк)

Файл `.xlsx` — это ZIP-архив с XML внутри. Мы пишем оба формата вручную,
чтобы не тянуть 900 КБ библиотеки в закрытый контур.

### CRC32

```javascript
const CRC = (() => {
  const t = new Uint32Array(256);
  for (let i = 0; i < 256; i++) {
    let c = i;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xEDB88320 ^ (c >>> 1) : c >>> 1;
    t[i] = c >>> 0;
  }
  return t;
})();
```

> **Где это в коде:** `web/js/xlsx-writer.js:18` — таблица CRC32;
> `web/js/xlsx-writer.js:35` — сборка ZIP; `web/js/xlsx-writer.js:112` —
> генерация XML листа.

Контрольная сумма, обязательная для каждого файла в ZIP. `>>>` — сдвиг
вправо без учёта знака, `^` — исключающее ИЛИ. Таблица считается один раз при
загрузке.

### ZIP без сжатия

```javascript
lv.setUint32(0, 0x04034B50, true);   // сигнатура «локальный заголовок файла»
lv.setUint16(8, 0, true);            // метод сжатия: 0 = STORE (без сжатия)
```

`DataView` пишет числа по конкретным смещениям. Третий аргумент `true` —
**little-endian**, порядок байтов, принятый в формате ZIP. Метод STORE
избавляет от необходимости реализовывать deflate: Excel такой архив открывает.

### Ячейки

```javascript
return typeof obj.v === 'number' && isFinite(obj.v)
  ? `<c r="${ref}"${s}><v>${obj.v}</v></c>`
  : `<c r="${ref}"${s} t="inlineStr"><is><t>${esc(obj.v)}</t></is></c>`;
```

Числа пишутся как числа (`<v>`), текст — как inline-строка. Это принципиально:
если выгрузить суммы текстом, в Excel по ним не посчитается ни одна формула.

## 4.9. `excel-export.js` — сборка книги и скачивание

```javascript
function download(company, data, offline) {
  const bytes = build(company, data, offline);
  const blob = new Blob([bytes], {
    type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
  });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `АББ_${company.inn}_${new Date().toISOString().slice(0, 10)}.xlsx`;
  document.body.appendChild(a);
  a.click();
  a.remove();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}
```

> **Где это в коде:** `web/js/excel-export.js:203` — `build` (сборка листов);
> `web/js/excel-export.js:217` — `download`.

**Blob** — «двоичный объект» в памяти. **`URL.createObjectURL`** выдаёт ему
временный адрес вида `blob:http://localhost/...`. Дальше создаётся невидимая
ссылка с атрибутом `download`, программно нажимается и удаляется.
`revokeObjectURL` освобождает память — без него blob висит до перезагрузки
страницы.

Никакого сервера в этой операции нет: файл рождается и скачивается в браузере.

### Баг с таймером, который стоит помнить

