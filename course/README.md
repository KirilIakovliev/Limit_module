# Лимитный модуль АББ — курс по проекту

Шесть лекций, разбирающих проект целиком: от общей схемы до запуска в Docker.
Материал построен на реальном коде — все примеры взяты из файлов проекта,
включая ошибки, которые мы совершили по дороге, и то, чем они лечились.

Читать желательно по порядку: каждая следующая опирается на предыдущую.
Лекция 7 — сборочная: она повторяет пройденное, но собирает куски в рабочее
целое. Если после первых шести осталось ощущение разрозненности, читайте её
сразу и возвращайтесь к деталям по ссылкам.

В тексте под ключевыми фрагментами есть пометки **«Где это в коде»** с точным
файлом и номером строки — например, `web/css/styles.css:211`. Открывайте файл
рядом и смотрите фрагмент в окружении.

Вопросы для самопроверки в конце каждой лекции снабжены скрытыми ответами.

**Если вместо кнопки «Показать ответ» вы видите текст `<details>`** — ваш
просмотрщик markdown не выполняет HTML. Откройте `course.html`: это тот же
курс одним файлом, с оглавлением и работающими кнопками. Пересобрать его
после правок в лекциях:

```bash
python3 tools/build_course.py
```

## Живые демонстрации

В лекциях 1 и 3–7 есть блоки **«Демонстрация»**: команда, реальный вывод и
разбор того, что в этом выводе означает каждая строка. Все выводы получены
запуском на настоящей базе проекта и настоящем коде — ни одна цифра не
выдумана. Например, разница в 270 раз между двумя вариантами `ORDER BY`
показана планами `EXPLAIN ANALYZE`, а SQL-инъекция — реальным ответом базы,
вернувшей все 28 строк вместо нуля.

Для лекции 2 (CSS) демонстрации вынесены в отдельные страницы —
`course/demo/*.html`. Откройте их двойным кликом: в каждой сверху сломанный
вариант, снизу правильный.

## Чему учит проект помимо кода

Пять сквозных идей, которые повторяются во всех лекциях:

**Замеряйте, не угадывайте.** Кэш в Redis оказался в 560 раз медленнее базы.
Одна строчка `ORDER BY ... USING ~<~` ускорила поиск в 130 раз. Ни то, ни
другое нельзя было предсказать, глядя на код.

**Один источник истины.** Данные живут в Postgres. «Единый сублимит» не
хранится, а считается суммой лимитов — иначе он однажды разойдётся со
слагаемыми.

**Идемпотентность.** Миграция, которую можно применить дважды без вреда,
позволяет применять её при каждом старте и не вести учёт «что накатано».

**Ошибки должны быть видимыми.** Тихий откат на демо-данные привёл к тому,
что выдуманные цифры принимались за настоящие. Появился жёлтый значок.

**Отложенное действие нужно уметь отменить.** Таймер скрытия панели прятал
её сразу после показа, если API отвечал быстрее 350 мс.

## Ошибки проекта как учебный материал

Каждая разобрана в соответствующей лекции — они полезнее готовых решений:

| Ошибка | Где | Урок |
|---|---|---|
| Мёртвое CSS-правило ниже нового | Л2 | При равной специфичности побеждает нижнее |
| `z-index` не работал | Л2 | `transform` создаёт контекст наложения |
| Прозрачная рамка на градиенте | Л2 | Фон просвечивает сквозь `border-color: transparent` |
| `random()` в LATERAL | Л3 | Некоррелированный подзапрос вычисляется однократно |
| `Sort` в плане запроса | Л3 | Порядок сортировки должен совпадать с индексом |
| Миграция не применилась | Л3, Л6 | `initdb.d` работает только на пустом томе |
| Панель исчезала сразу после появления | Л4 | Незаснятый `setTimeout` |
| `400 Invalid HTTP request` | Л4, Л5 | В URL допустим только ASCII |
| Правка «не применилась» | Л6 | Замена по строке молча не сработала — проверяйте результат |

## Как пользоваться курсом

Читать подряд, держа проект открытым в редакторе: почти каждый фрагмент кода
в лекциях можно найти в файлах и посмотреть в контексте. В конце каждой лекции
есть вопросы для самопроверки — если ответ не приходит сразу, вернитесь к
соответствующему разделу.
