# Spec: group currency layout and events tab

Зафиксировано: 2026-09-29. Экран карточки ГК и вкладка «События». API и SQL не менялись.

## Карточка группы

Источник — только `t_lm_1_2_gk_info`. Строка витрины: участник (`party_inn`) и валюта (`currency`). Разные валюты не складываются.

- «Единый лимит» — один блок. В каждой сумме валюты идут строками. «… по клиенту» — SUM участников этой валюты. «… на гк» — одно значение на валюту (MAX, оно повторяется в строках участников). «Крышка» по-прежнему пустая: колонки в DDL нет. Если утилизация валюты больше лимита, красная только её строка.
- «Компании в структуре ГК» — одна строка на ИНН. Название берётся из `t_lm_1_2_clients` по этому ИНН. Три сублимита — строки валют из полей «единый … по клиенту», без суммы между валютами. Кнопка «Перейти» одна на ИНН.

## События

Вкладка прототипа возвращена. Отдельного запроса нет: список считается в браузере по уже загруженной карточке.

- Лимиты: поля витрины `t_lm_1_3_limits` (`lim_value`, `lim_utiled`, `rest_lim`, `end_date`). 100% и выше — критично, 90–100% и срок в ближайшие 90 дней — наблюдение.
- Правила отчётности и резервов в коде остались, данных под них нет, событий не дают.
- В Excel вкладка не выгружается.
